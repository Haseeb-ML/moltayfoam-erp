# MoltyFoam ERP

A simple Retail Dealership ERP Web Application for managing multiple showrooms, orders, deliveries, and more.

## Setup Instructions

In simple words, here is how you can run this project on your computer:

### 1. Requirements
Make sure you have [Node.js](https://nodejs.org/) installed on your computer.

### 2. Install Packages
Open your terminal (or command prompt) in this project folder and run:
```bash
npm install
```

### 3. Setup Database (Initial Data)
If you are running this for the first time, you might want to add some basic test data:
```bash
npm run seed
```

### 4. Run the Application
Start the server by running:
```bash
npm start
```

### 5. Open the Website
Once the server starts running, open your web browser and go to:
[http://localhost:3000](http://localhost:3000) (or whatever port is shown in your terminal).
